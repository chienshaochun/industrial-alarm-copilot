# Industrial Alarm Copilot 產品規格書

## 1. 產品目標

Industrial Alarm Copilot 協助設備可靠度或維護工程師檢視大量設備警報、辨識有意義的事件時間窗、尋找相似的歷史事件，並估計接下來可能出現的警報。

本產品是一套以證據輔助調查的工具，不會取代現場操作人員、診斷設備的實際物理根因，也不會直接提供維修操作指令。

## 2. 目標使用者

主要使用者是具備以下需求的設備可靠度或維護工程師：

- 需要檢視多台設備的歷史警報；
- 需要區分重複發生的模式與異常事件；
- 在決定後續調查方向前，希望先查看歷史證據；
- 不一定具備機器學習專業背景。

## 3. 問題描述

原始警報紀錄是一連串依時間排列的事件。使用者必須手動判斷哪些警報屬於同一事件、類似模式是否曾經發生，以及這些模式之後通常出現哪些警報。當警報代碼種類多、罕見警報可能很重要，且不同設備的資料分布不一致時，人工判讀會變得困難。

ALPI 資料集具體呈現了這些限制：資料包含 20 台設備、154 種匿名警報代碼與 444,834 筆事件，且警報類別分布高度不平衡。

## 4. 核心使用流程

1. 使用者選擇設備與觀察時間範圍。
2. 應用顯示警報時間軸與基本分布摘要。
3. 應用將時間上相關的警報組成事件時間窗。
4. 使用者選擇一個事件進行調查。
5. 應用檢索相似的歷史事件，並引用其設備識別碼與時間範圍。
6. 預測模型列出未來時間窗內可能出現的警報排序。
7. Copilot 分別摘要觀察到的事實、檢索證據與模型預測。

## 5. MVP 功能

### 5.1 資料集探索

- 依設備與時間範圍篩選事件。
- 顯示事件數量、不同警報數量與最常出現的警報。
- 視覺化呈現警報活動的時間分布。

### 5.2 事件建立

- 使用有文件說明且可調整的時間間隔規則，將相關警報分組。
- 為每個事件產生穩定的識別碼。
- 顯示事件起訖時間、持續時間、事件筆數與警報代碼摘要。

### 5.3 相似事件檢索

- 針對選定事件，檢索最相似的歷史事件時間窗。
- 顯示相似度分數與用於比較的證據。
- 禁止將未來事件當成當下事件的歷史證據，避免時間洩漏。

### 5.4 後續警報預測

- 排列未來時間窗內最可能出現的警報。
- 顯示信心分數或模型分數，但不將預測表達為確定事實。
- 分別評估常見與罕見警報。

### 5.5 具證據的 Copilot 摘要

- 分開呈現觀察到的事實、檢索到的歷史證據與模型預測。
- 引用歷史事件的識別碼與時間範圍。
- 證據不足時明確說明。
- 不虛構警報含義、物理根因或維修程序。

## 6. MVP 非目標

- 串接生產設備的即時資料
- 使用者帳號、角色或多租戶功能
- 設備物理根因診斷
- 維修或安全操作指示
- 剩餘使用壽命（RUL）估計
- 持續進行的線上模型訓練
- 行動裝置應用

## 7. 產品限制

- 警報代碼與設備識別碼已經匿名化。
- 資料集未提供警報說明、實際根因或維修 SOP。
- 時間相關的模型評估必須使用時間順序切分。
- 沒有 LLM API Key 時，應用的基本功能仍必須可以操作；AI 摘要是建立在 deterministic analysis 與模型輸出之上的選配功能。

## 8. MVP 驗收條件

使用者能完成以下操作時，即視為 MVP 完成：

1. 依照文件指令在本機啟動應用；
2. 選擇設備與歷史觀察時間窗；
3. 檢視產生的事件及其原始警報；
4. 在沒有時間洩漏的情況下檢索相似事件；
5. 查看 Top-K 後續警報預測與模型評估結果；
6. 產生或預覽受證據約束的事件調查摘要；
7. 透過測試或文件化指令重現主要資料處理與評估結果。

## 9. 成功指標

- 檢索：Hit@K、Precision@K、Recall@K、MRR、NDCG@K
- 預測：Precision@K、Recall@K、macro F1、各警報的 support
- 工程品質：自動化測試、可重現資料流程、穩定啟動
- 產品展示：可在 90 秒內完成完整的事件調查流程
